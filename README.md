# 中国就业市场 AI 影响分析 ｜ 龙御2037

> 280 个中国职业的薪资、学历、就业前景与 AI 影响程度可视化。
> ⚠️ 数据由 AI 模型估算，**仅供趋势科普，不代表官方统计**。

## 简介

本网页由 **龙御2037** 出品（公众号「龙御2037」），围绕「中国就业市场与 AI 影响」主题，模拟整理中国常见职业数据，并结合 AI 对职业任务的自动化潜力、工具替代程度、行业采纳速度、物理/社交技能需求等因素，对不同职业进行 **AI 影响评分**，用可视化方式呈现人工智能对就业结构的潜在影响。

## 主要功能

- 职业树状图 Treemap（面积 = 估算就业人数，颜色 = AI 影响程度）
- 4 张摘要图表（就业 / 影响概览）
- 全职业数据总览表（支持关键词搜索、行业 / 产业 / AI 影响筛选）
- 职业详情查看
- 深色模式切换
- 响应式，适配电脑端与移动端

## 数据说明

- 约 280 个职业基于 2024 年三次产业就业结构估算：第一产业约 22.2%、第二产业约 29.0%、第三产业约 48.8%。
- **薪资中位数、学历要求、就业前景、AI 影响评分均为 AI 模型估算的模拟数据，非官方统计**，请勿直接引用作决策依据。
- 页内「参考资料链接」附国家统计局、ILO、OECD、WEF 等公开报告，供进一步核实。
- 引用请谨慎；本页不构成任何职业或投资建议。

## 技术栈

- 纯静态 HTML / CSS / JavaScript（单文件，无构建依赖、无第三方图表库）
- Treemap 为自绘 SVG，零运行时依赖

## 部署（Vercel + 自有域名）

当前目标：挂到龙御自有域名 `aidesignlab.cc` 下，使用子域 **`jobs.aidesignlab.cc`**（最干净，不干扰主站）。

1. **推代码到你自己的 GitHub**（建议新建仓库 `ai-impact-jobs`），把本目录内容 push 上去。
2. **Vercel → New Project → Import** 该仓库 → Framework 选 `Other` → Deploy（或直接把文件夹拖到 Vercel 网页部署，无需 GitHub）。
3. 部署成功后，进入 **Project Settings → Domains**，添加 `jobs.aidesignlab.cc`。
4. 按 Vercel 提示，到 `aidesignlab.cc` 的域名商后台加一条 **CNAME 记录**，指向 Vercel 给出的值（通常形如 `cname.vercel-dns.com`）。
5. 等待 DNS 生效（通常几分钟到几小时），即可访问 **https://jobs.aidesignlab.cc**。

> 注：`aidesignlab.cc` 主站已在 Vercel，新增子域无需改动主站项目。若想用路径 `aidesignlab.cc/jobs`，需在主站项目里配置 rewrite，较复杂，不推荐。
